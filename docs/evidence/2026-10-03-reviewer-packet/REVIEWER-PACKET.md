Annotations describe behavior; server-side grant, live membership, and seat authorization remain separate checks. `check` creates durable batches and ACK permanently advances the cursor; it is mutating and destructive, and its composite operation is not marked idempotent. Its repeated ACK of an older batch does not ACK a newer batch. Claim and messaging retries retain the same request ID and arguments. Additive, append-only messages are marked non-destructive; they cannot be recalled or edited. `openWorldHint=false` describes operations confined to the CommonSwarm workspace, including participants there; it does not imply a private per-chat boundary. [Authority](https://github.com/yulanventures/commonswarm/blob/b8a97e10eee5c322b7d57d70280ba4ad51527338/supabase/functions/_shared/hosted-seat-auth.ts#L83-L139), [batch semantics](https://github.com/yulanventures/commonswarm/blob/b8a97e10eee5c322b7d57d70280ba4ad51527338/src/protocol/hosted-check.ts#L110-L162), [immutability](https://github.com/yulanventures/commonswarm/blob/b8a97e10eee5c322b7d57d70280ba4ad51527338/SECURITY.md#L40-L53).

Schema bounds: seat name 1–80 code points; request ID 8–72 ASCII letters/digits/underscore/hyphen; text body 1–8,000 characters; recipients 1–20 `{kind: user|agent, id: UUID}` records. ## Reliability and remaining review limitations

Source defaults are 128 KiB request, 64 KiB response, 25-second MCP timeout, and four concurrent requests per handler; overload returns 429 with Retry-After 1. OAuth defaults are 64 KiB body and ten-second timeout. Signal source quotas are 120 per credential/hour and 1,000 per workspace/hour. DCR limiter defaults are ten registrations per source IP/hour and thirty per redirect-host bucket/hour, process-local and reset on restart. These are source configuration facts, not measured production settings or vendor account quotas.
