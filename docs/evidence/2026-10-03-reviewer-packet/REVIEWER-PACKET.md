## Reliability and remaining review limitations

Source defaults are 128 KiB request, 64 KiB response, 25-second MCP timeout, and four concurrent requests per handler; overload returns 429 with Retry-After 1. OAuth defaults are 64 KiB body and ten-second timeout. Signal source quotas are 120 per credential/hour and 1,000 per workspace/hour. DCR limiter defaults are ten registrations per source IP/hour and thirty per redirect-host bucket/hour, process-local and reset on restart. These are source configuration facts, not measured production settings or vendor account quotas. [MCP bounds](https://github.com/yulanventures/commonswarm/blob/b601880ca8b18d82505f1968ce6d1e67ed16c5bd/supabase/functions/mcp/index.ts#L81-L85), [429](https://github.com/yulanventures/commonswarm/blob/b601880ca8b18d82505f1968ce6d1e67ed16c5bd/supabase/functions/mcp/protocol.ts#L236-L237), [OAuth bounds](https://github.com/yulanventures/commonswarm/blob/b601880ca8b18d82505f1968ce6d1e67ed16c5bd/services/mcp-auth/src/config.js#L212-L213), [signal quotas](https://github.com/yulanventures/commonswarm/blob/b601880ca8b18d82505f1968ce6d1e67ed16c5bd/supabase/functions/command/index.ts#L699-L700), [DCR limiter](https://github.com/yulanventures/commonswarm/blob/b601880ca8b18d82505f1968ce6d1e67ed16c5bd/services/mcp-auth/src/registration.js#L79-L83).
