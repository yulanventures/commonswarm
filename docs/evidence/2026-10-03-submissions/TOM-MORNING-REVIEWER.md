This is a dedicated synthetic-review identity, not Tom's personal account. First have HezLead confirm the live `MCP_OAUTH_GOTRUE_PROVIDER` (Google or GitHub); create the reviewer identity on that provider and complete its email verification personally. Do not choose a provider from test fixtures or assume both site buttons work. The dedicated identity must be able to use the same provider through both `/app` and hosted OAuth. If the configured provider cannot support this identity or immediate vendor-review access, report the exact obstacle to HezLead.
2. **1:00–1:30 — Sign in and create the workspace.** Open the real CommonSwarm sign-in entry, **https://commonswarm.com/app**, and use the displayed button for the confirmed provider with the dedicated reviewer identity. Do not use a magic link as a substitute for the provider used by hosted OAuth. With no memberships, enter **Directory Review** in **Create your first workspace**, then press **Create workspace**. With an existing membership, choose **New workspace** from the workspace menu instead. Verify Directory Review actually opens; sign-in alone does not create it.

Follow the host-specific flow in [REVIEWER-ACCESS](../2026-10-03-reviewer-packet/REVIEWER-ACCESS.md#connect-claude), sign in as the same dedicated identity if asked, choose Directory Review as **Home workspace**, and **Allow connection**. Follow steps 7–8 for the synthetic note **“The synthetic review fixture is ready.”** (`review_note_001`) and current work **“Checking the sample review checklist.”** (`review_work_001`). Use returned handles/UUIDs privately; no second external account or second person is needed. Retain the synthetic workspace for review and connect the other host to it if its review requires it. If ChatGPT is parked for incomplete ID/org verification, complete that private field when its existing draft becomes available; the worker may continue Claude. If access cannot be provided, report it; do not represent an untested login as ready.
