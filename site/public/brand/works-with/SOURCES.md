# Works-with marks: sources and usage rules

Collected 2026-10-01 from each owner's site, brand page, or asset CDN (no sign-in, no forms).
Each file is the owner's mark as supplied. Two raster marks were resized (Gemini was also
re-encoded as WebP), as listed below; no mark was recoloured, redrawn, cropped, isolated from a
lockup, or combined with another mark.

Two agents are named on the homepage without a mark, and no file for them is shipped:

- **Claude.** Anthropic's [trademark guidelines](https://www.anthropic.com/legal/trademark-guidelines)
  (effective 1 Aug 2024) permit use of its marks only as Anthropic specifically allows, which
  for site use means asking first (marketing@anthropic.com). No approval covering this page
  has been requested or received. The press-kit spark (`Claude Spark - Clay.svg`) stays out
  of the site until written approval is recorded here.
- **Codex / ChatGPT.** The only standalone blossom OpenAI publishes on
  [openai.com/brand](https://openai.com/brand/) (`Blossom_Light.svg`) is a clear-space
  construction sheet: a gridded blossom beside a plain one in a 1183x719 frame. Shown as
  supplied it is a diagram, not a logo; cutting the blossom out of it would be the cropping
  the rules forbid. The earlier file here was the blossom path isolated from the ChatGPT
  header lockup on chatgpt.com, which is also a modification. The longer guide at
  brand.openai.com needs a sign-in. A display file goes in only when OpenAI supplies one that
  can be shown unchanged.

The homepage shows these marks only to name agents people already use. The wording is "Works
with" / "Bring the agents you already use"; it never says partner, certified, endorsed, or
one-click. Every page footer carries "Product names and logos are trademarks of their owners."
Each mark sits on its own white disc with padding for clear space, in both colour themes,
because several owners supply only a dark mark and ask that it not be altered.

2026-10-12 — Tom chose to show Muse in the homepage headline and Muse, Dot and Grok bot
as example hosted agents in the app pictures, with their availability explained in
the hero caption; Muse and Grok bot also appear in the Coming soon orbit. Works with stays
Claude only, and the closing row uses local agents. Each unchanged vendor file sits
on its own white disc inside the agent's rounded square tile in both colour themes.
Non-tile marks have padding of about 0.2 times the avatar width; tile marks such as
Muse already include white margin and get no extra padding. The owner's photo badge
overlaps the tile's lower-right corner, with its ring clear of the vendor mark.
