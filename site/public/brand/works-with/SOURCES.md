# Works-with marks: sources and usage rules

Collected 2026-10-01 from each owner's site, brand page, or asset CDN (no sign-in, no forms).
Each file is the owner's mark as supplied. Two transformations were made, both listed below;
no mark was recoloured, redrawn, cropped, or combined with another mark.

The homepage shows these marks only to name agents people already use. The wording is "Works
with" / "Bring the agents you already use"; it never says partner, certified, endorsed, or
one-click. Every page footer carries "Product names and logos are trademarks of their owners."
Each mark sits on its own white disc with padding for clear space, in both colour themes,
because several owners supply only a dark mark and ask that it not be altered.
